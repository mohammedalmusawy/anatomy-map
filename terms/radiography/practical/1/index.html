Radiographالصورة الشعاعيةري-دي-گ-راف /ɹˈAdiəɡɹˌæf/صورة لجزء من الجسم تنتجها الأشعة السينية على مستقبِل الصورة.
Image receptor (IR)مستقبِل الصورةي-ميج ر-سيپ-تر آي-آر /ˈɪmɪʤ ɹəsˈɛptəɹ IR/الجهاز الذي يلتقط الصورة الخارجة من المريض (كاسيت أو جهاز رقمي).
Central ray (CR)الشعاع المركزيسينت-رل ري سي-آر /sˈɛntɹəl ɹˈA CR/الجزء الأوسط من حزمة الأشعة، وهو الأقل تباعداً.
Anterior / Posteriorأمامي / خلفيان-تي-ري-ر / پاس-تي-ري-ر /æntˈɪɹiəɹ pɑstˈɪɹiəɹ/الأمامي جهة الوجه والبطن؛ والخلفي جهة الظهر.
Medial / Lateralإنسي / وحشيمي-دي-ل / لا-ت-رل /mˈidiəl lˈæTəɹəl/الإنسي الأقرب لخط منتصف الجسم؛ والوحشي الأبعد عنه.
Proximal / Distalقريب / بعيدپراك-سمل / ديستل /pɹˈɑksəmᵊl dˈɪstᵊl/القريب أقرب لبداية الطرف أو للجذع؛ والبعيد أبعد عنه.
Cephalic / Caudalرأسي / ذيليس-فا-ليك / كودل /səfˈælɪk kˈɔdᵊl/الرأسي باتجاه الرأس؛ والذيلي باتجاه القدمين (يستعمل لزاوية الشعاع المركزي).
Sagittal / Coronal / Transverseسهمي / إكليلي / مستعرضسا-جي-تل / ك-رو-نل / ترانز-ڤيرس /sˈæʤɪtəl kəɹˈoʊnəl tɹˌænzvˈɜɹs/السهمي يقسم الجسم يميناً ويساراً، والإكليلي أماماً وخلفاً، والمستعرض أعلى وأسفل.
PA / APخلفي أمامي / أمامي خلفيپي-ايه / ايه-پي /PA AP/PA الشعاع يدخل من الخلف ويخرج من الأمام؛ AP بالعكس.
Obliqueمائلب-ليك /əblˈik/إسقاط يكون فيه الجزء مُداراً، ويُذكر معه اتجاه الدوران.
Supine / Proneاستلقاء على الظهر / انبطاحسو-پاين / پرون /sˈupˌIn pɹˈOn/الاستلقاء على الظهر والوجه للأعلى؛ والانبطاح على البطن والوجه للأسفل.
Erect / Decubitusقائم / اضطجاعيريكت / ديك-يو-بي-تس /əɹˈɛkt dɪkjˈubɪtəs/القائم واقفاً أو جالساً؛ والاضطجاعي مستلقياً مع شعاع أفقي.
Flexion / Extensionثني / بسطفليك-شن / يكس-تينشن /flˈɛkʃən ɪkstˈɛnʃᵊn/الثني يقلّل الزاوية بين عظمين؛ والبسط يزيدها.
Abduction / Adductionتبعيد / تقريبب-داك-شن / داك-شن /əbdˈʌkʃən ədˈʌkʃən/التبعيد تحريك الطرف بعيداً عن خط المنتصف؛ والتقريب نحوه.
